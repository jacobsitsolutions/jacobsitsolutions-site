IMPLEMENTED IN THE PILOT

Account visibility

Account status, creation and password dates, and configurable inactivity-review candidates. Older replicated logon timestamps are indicators for human review.

IMPLEMENTED IN THE PILOT

Group relationships

Direct, primary, and nested user-to-group relationships, with selected privileged groups identified by SID and an observed membership path.

IMPLEMENTED IN THE PILOT

A reusable evidence package

A dated HTML summary, eight CSV exports, structured JSON, collection settings, query outcomes, and file hashes.

IMPLEMENTED IN THE PILOT

Human decisions, visible gaps

A worksheet for owners, reviewers, decisions, reasons, and ticket references. Collection errors and unresolved membership references remain visible.

NEW IN V0.2.0

Guided setup and clearer failures

A console menu, local prerequisite checks, output-access checks, progress messages, and clearer failure results. The setup check makes no directory queries.

NEW IN V0.2.0

Verify the evidence files

Compare exported files with their recorded hashes and sizes. Missing, changed, or unlisted files are flagged for review; an unsigned manifest does not authenticate the evidence.

Focused first-release scope

One on-premises Active Directory domain and AD user objects. Live collection is intended for Windows PowerShell 5.1 with Microsoft's ActiveDirectory module. Automated checks pass on both PowerShell test engines; live collection has passed in one isolated lab using Windows PowerShell 5.1. Wider environment compatibility remains under review. The code performs directory reads and writes local report files. It does not disable, delete, or modify accounts.

This pilot does not assess computer accounts, managed service accounts, effective resource permissions, other domains, Entra ID, Microsoft 365, or MFA. A membership report is not a full security assessment or a compliance certification.

Common questions

Before you get started.

Can I download or buy a tool today?

The AD Access Review toolkit is an internal pilot and is not publicly available for download or purchase. You can inspect the synthetic sample report today. Real product download and purchase links will appear after validation and release preparation.

What has actually been tested?

The latest automated suite passes 90 checks per Windows PowerShell 5.1 and PowerShell 7 engine, including packaging and release-record safeguards. Separately, the original full pilot package passed 20 package/failure checks and repeated 50 live-directory comparisons as an ordinary reader in one isolated Windows Server 2025 lab. These are defined test scopes, not a production-readiness guarantee. Read the validation details and remaining gaps.

What remains before release?

Independent tester feedback, three real AD timestamp scenarios, wider compatibility and representative-scale checks remain open. We are also preparing clearer report wording and finalizing supported scope, distribution/signing, licensing, support, refunds and verified payment/download delivery. There is no public release date or active checkout yet.

Do I need to schedule a call?

Our planned products are intended for self-service use. You can explore the roadmap here and send product questions or feature suggestions by email.

Do you provide managed IT or emergency support?

Jacobs IT Solutions is focused on software and automation. This site does not offer managed IT contracts, phone support, or emergency troubleshooting services.

Will the tools change my environment?

The AD Access Review pilot is implemented with read-only directory queries and local report-file output. It does not disable, delete, or modify AD accounts. Future products will document their own permissions and behavior before release.
