Complete the review

Start with a separate worksheet copy. Keep all generated evidence files unchanged; edit only a working copy outside the original evidence folder.

  1. Check the coverage, selected groups, and collection issues.
  2. Use the supplied Test-EvidencePackage.ps1 checker to verify the original evidence before editing any files.
  3. Make a separate copy of reviewer-worksheet.csv in an approved review folder outside the original evidence folder.
  4. Open only the copy and assign a reviewer and owner. Record a decision, reason, UTC date, and ticket reference for each account. Confirm exceptions and potential inactivity with the owner.
  5. Retain the completed worksheet and approvals separately. Handle any approved changes through your existing administrative process.

A current snapshot cannot prove a historical review or that access was revoked. This toolkit performs no remediation and provides no compliance certification.
