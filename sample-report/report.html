One domain, AD user objects, and collected group relationships. Includes primary-group membership and nested paths through collected groups. Selected privileged paths require security groups at every hop. This is a membership review, not an effective-permissions calculation.

Does not evaluate computers, managed service accounts, foreign principals, other domains, SID history, ACL delegation, local administrators, GPO effects, Entra ID, Microsoft 365, MFA, or application access. Cross-domain links cannot be expanded. Attribute-level permission restrictions may be silent.

lastLogonTimestamp is replicated approximately and can be delayed. A missing value is not proof of never logging on. Inactivity, password settings, and adminCount are review indicators, not automatic findings. Collection is not transactionally consistent; the directory can change between queries.

Complete the review

  1. Check the coverage, selected groups, and collection issues.
  2. Open reviewer-worksheet.csv and assign a reviewer and owner.
  3. Record a decision, reason, UTC date, and ticket reference for each account. Confirm exceptions and potential inactivity with the owner.
  4. Preserve the original evidence files. Save the completed worksheet as a new file and retain approvals separately.

A current snapshot cannot prove a historical review or that access was revoked. This toolkit performs no remediation and provides no compliance certification.
